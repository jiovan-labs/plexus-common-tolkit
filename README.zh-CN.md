# Plexus 通用工具包

玖漫 plexus-common-tolkit 是面向 Java 体系的工具类集合，其中的类被视为足够通用，因而值得纳入各类工具库。

## 快速开始

- 导入依赖

```xml

<dependency>
    <groupId>com.jiovan.plexus</groupId>
    <artifactId>plexus-common-tolkit</artifactId>
    <version>LATEST</version>
</dependency>
```

- 其中包含许多有用的包，可能对你大有帮助，可按需使用。

| 包 | 描述 |
|-------------|-------------------------------------------------------------------------------|
| annotation | 标注在元素上以启用某些能力 |
| constant | 各类常量 |
| converter | Apache BeanUtils 的额外转换器 |
| enumeration | 实用枚举 |
| exception | 用于满足自定义需求的扩展异常 |
| function | 支持复杂 Predicate/Consumer 的 Lambda 函数 |
| identity | 帮助生成标识符，通常为 UUID |
| iterator | 用于遍历枚举/集合的增强迭代器 |
| locale | 可处理区域设置，例如中文日期、中文数字、人民币金额 |
| structure | 用于表示数据组合的多种结构 |
| util | 可加速开发的强大工具类 |
| validation | 用于校验的实用序列与分组 |
