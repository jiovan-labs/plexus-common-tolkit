# Plexus 通用工具包

玖漫 plexus-common-tolkit 是面向 Java 體系的工具類集合，其中的類被視為足夠通用，因而值得納入各類工具庫。

## 快速開始

- 匯入相依性

```xml

<dependency>
    <groupId>com.jiovan.plexus</groupId>
    <artifactId>plexus-common-tolkit</artifactId>
    <version>LATEST</version>
</dependency>
```

- 其中包含許多有用的包，可能對你大有幫助，可按需使用。

| 包 | 描述 |
|-------------|-------------------------------------------------------------------------------|
| annotation | 標註在元素上以啟用某些能力 |
| constant | 各類常量 |
| converter | Apache BeanUtils 的額外轉換器 |
| enumeration | 實用列舉 |
| exception | 用於滿足自定義需求的擴充套件異常 |
| function | 支援複雜 Predicate/Consumer 的 Lambda 函式 |
| identity | 幫助生成識別符號，通常為 UUID |
| iterator | 用於遍歷列舉/集合的增強迭代器 |
| locale | 可處理區域設定，例如中文日期、中文數字、人民幣金額 |
| structure | 用於表示資料組合的多種結構 |
| util | 可加速開發的強大工具類 |
| validation | 用於校驗的實用序列與分組 |
